# Tutorial Steps

This document outlines the sequence of lessons in the DirectX Tool Kit Getting Started tutorial.

Each lesson is documented on the [DirectXTK wiki](Getting-Started.md).

## Lesson Sequence

| # | Lesson | Wiki Page | Summary |
| --- | -------- | ----------- | --------- |
| 0 | Prerequisites | [Getting Started](Getting-Started.md) | Verify required tools: Visual Studio, Windows SDK, vcpkg, and Git |
| 1 | Project Setup | [Getting Started](Getting-Started.md) | Create a new Direct3D 11 project using the d3d11game_vcpkg template |
| 2 | Building the project | | Build the project and resolve any dependencies |
| 3 | Adding DirectXTK | [Adding the DirectX Tool Kit](Adding-the-DirectX-Tool-Kit.md) | Integrate DirectXTK into the project via vcpkg |
| 4 | Sprites and Textures | [Sprites and textures](Sprites-and-textures.md) | Render 2D sprites using SpriteBatch |
| 5 | Drawing Text | [Drawing text](Drawing-text.md) | Render text using SpriteFont |
| 6 | Simple Rendering | [Simple rendering](Simple-rendering.md) | Draw simple triangle primitives |
| 7 | 3D Shapes | [3D shapes](3D-shapes.md) | Use GeometricPrimitive for standard 3D shapes |
