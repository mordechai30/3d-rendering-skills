# CD3D11\_VIEWPORT::operator const D3D11\_VIEWPORT&() method

This operator returns the address of a [**D3D11\_VIEWPORT**](https://msdn.microsoft.com/en-us/library/ff476260(v=vs.85)) structure that contains the data from the [**CD3D11\_VIEWPORT**](jj151722(v=vs.85)) instance.

## Syntax

```
CD3D11_VIEWPORT* operator const D3D11_VIEWPORT&() const;
```

## Parameters

This method has no parameters.
