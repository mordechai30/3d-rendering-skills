# CD3D11\_QUERY\_DESC::operator const D3D11\_QUERY\_DESC&() method

This operator returns the address of a [**D3D11\_QUERY\_DESC**](https://msdn.microsoft.com/en-us/library/ff476195(v=vs.85)) structure that contains the data from the [**CD3D11\_QUERY\_DESC**](jj151648(v=vs.85)) instance.

## Syntax

```
CD3D11_QUERY_DESC* operator const D3D11_QUERY_DESC&() const;
```

## Parameters

This method has no parameters.
