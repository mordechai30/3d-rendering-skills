# ID3DBlob::GetBufferSize method

Retrieves the size, in bytes, of the blob's data.

## Syntax

```
SIZE_T GetBufferSize();
```

## Parameters

This method has no parameters.

## Return value

Type: **[SIZE\_T](https://msdn.microsoft.com/en-us/library/aa383751(v=vs.85))**

Returns the size of the blob's data, in bytes.

## Remarks

The [**ID3DBlob**](ff728743(v=vs.85)) interface is type defined in the D3DCommon.h header file as a [**ID3D10Blob**](https://msdn.microsoft.com/en-us/library/bb173507(v=vs.85)) interface, which is fully defined in the D3DCommon.h header file.

```
typedef ID3D10Blob ID3DBlob;
```

[**ID3DBlob**](ff728743(v=vs.85)) is version neutral and can be used in code for any Direct3D version.
