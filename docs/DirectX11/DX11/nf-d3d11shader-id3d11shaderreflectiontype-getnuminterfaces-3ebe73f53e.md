# ID3D11ShaderReflectionType::GetNumInterfaces


## -description

Gets the number of interfaces.



## -returns

Type: <b><a href="/windows/desktop/WinProg/windows-data-types">UINT</a></b>

Returns the number of interfaces.

## -remarks
