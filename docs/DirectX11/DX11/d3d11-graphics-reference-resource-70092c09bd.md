# Resource Reference (Direct3D 11 Graphics)

The Direct3D API defines several API elements to help you create and manage resources.

| [Resource Interfaces](./d3d11-graphics-reference-resource-interfaces-3b00f24439.md)<br/> | There are a number of interfaces for the two basic types of resources: buffers and textures. This section describes the view interfaces. <br/> |
