| [**D3D\_REGISTER\_COMPONENT\_TYPE**](./ne-d3dcommon-d3d_register_component_type-1866adca15.md)<br/>           | Values that identify the data types that can be stored in a register.<br/>                                                                                                                                                                                                                                                           |

| [**D3D\_TESSELLATOR\_OUTPUT\_PRIMITIVE**](./ne-d3dcommon-d3d_tessellator_output_primitive-e3a733fafb.md)<br/> | Values that identify output primitive types.<br/>                                                                                                                                                                                                                                                                                    |
| [**D3D\_TESSELLATOR\_PARTITIONING**](./ne-d3dcommon-d3d_tessellator_partitioning-3dd082aadf.md)<br/>          | Values that identify partitioning options.<br/>                                                                                                                                                                                                                                                                                      |
