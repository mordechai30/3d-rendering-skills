# Create an Effect (Direct3D 11)

An effect is created by loading the compiled effect bytecode into the effects framework. Unlike Effects 10, the effect must be compiled before creating the effect. Effects loaded into memory can be created by calling [**D3DX11CreateEffectFromMemory**](./d3dx11createeffectfrommemory-4ed7004121.md).
