## -description

Describes the blend state that you use in a call to [**D3D11Device1::CreateBlendState1**](./nf-d3d11_1-id3d11device1-createblendstate1-e3f7303ae1.md) to create a blend-state object.

> [!NOTE]
> This structure is supported by the Direct3D 11.1 runtime, which is available on Windows 8 and later operating systems.
