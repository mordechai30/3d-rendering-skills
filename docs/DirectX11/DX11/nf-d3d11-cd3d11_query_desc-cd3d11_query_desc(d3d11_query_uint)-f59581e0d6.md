# CD3D11_QUERY_DESC::CD3D11_QUERY_DESC(D3D11_QUERY,UINT)


## -description

Instantiates a new instance of a <a href="/previous-versions/windows/desktop/legacy/jj151648(v=vs.85)">CD3D11_QUERY_DESC</a> structure that is initialized with info for a query.

## -parameters

### -param query

Type: <b><a href="/windows/desktop/api/d3d11/ne-d3d11-d3d11_query">D3D11_QUERY</a></b>

A <a href="/windows/desktop/api/d3d11/ne-d3d11-d3d11_query">D3D11_QUERY</a>-typed value that specifies the type of query.

### -param miscFlags

Type: <b><a href="/windows/desktop/WinProg/windows-data-types">UINT</a></b>

A combination of <a href="/windows/desktop/api/d3d11/ne-d3d11-d3d11_query_misc_flag">D3D11_QUERY_MISC_FLAG</a>-typed values that are combined by using a bitwise OR operation. The resulting value specifies miscellaneous query behavior.
