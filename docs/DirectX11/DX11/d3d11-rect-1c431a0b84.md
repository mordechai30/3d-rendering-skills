# D3D11\_RECT

D3D11\_RECT is declared as follows:

``` syntax
typedef RECT D3D11_RECT;
```

For more information about this GDI rectangle structure, see [**RECT**](/windows/win32/api/windef/ns-windef-rect).

## Remarks

This structure is used for scissor rectangles by [**ID3D11DeviceContext::RSGetScissorRects**](./nf-d3d11-id3d11devicecontext-rsgetscissorrects-0daf6e4bc7.md) and [**ID3D11DeviceContext::RSSetScissorRects**](./nf-d3d11-id3d11devicecontext-rssetscissorrects-e3ef87d764.md).
